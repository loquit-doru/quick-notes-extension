Copy blocks for listing Quick Notes on aggregators and directories. Every claim
here matches what the extension actually does — the free tier really is 10 notes
of any length, search and folders really are Pro. If the product changes, change
this file in the same commit.

The point of these listings is twofold: a trickle of direct traffic, and
**backlinks**, which is what makes the sitemap at getquicknotes.vercel.app worth
having. Expect the SEO half to pay off over months, not days.

## Long description

```text
Quick Notes is a fast notepad that lives in your browser toolbar. Press Ctrl+Shift+Q from any tab, write, and get back to what you were doing.

Most note apps are too heavy for a passing thought, and most browser note extensions want an account before they will let you type. Quick Notes wants neither. Your notes are stored locally in your browser and work offline. There is no sign-up, no cloud sync, and no tracking.

Free: up to 10 notes of any length, instant popup from any tab, auto-save as you type, pinned notes, reminders with browser notifications, export to JSON or Markdown, and dark and light themes.

Pro is a one-time $2.99 unlock — not a subscription — and adds unlimited notes, full-text search, folders, a PIN lock for shared devices, longer trash recovery, and automatic local backups.

Every install starts with 7 days of full access, and only the days you actually open the extension are counted. Put it down for a month and the trial is still waiting for you.
```

## Where to submit

**AlternativeTo** — https://alternativeto.net
The highest-value one. Submit as an alternative to Google Keep and Sticky Notes;
people arrive there already looking to replace something. Needs the name, URL,
description, tags, platforms and licence.

**Tooltivity** — https://tooltivity.com
Curates browser extensions by category and already ranks for "best note taking
chrome extensions" style queries.

**Product Hunt** — https://producthunt.com
Not really a directory: it is a launch event, so hold it for a day you can be
present to answer comments. Covered separately from this file.

**Chrome-stats** — https://chrome-stats.com
Indexes the Chrome Web Store automatically. No submission needed; check the entry
is correct rather than creating one.

Before submitting anywhere, confirm the Chrome and Edge listings are out of
review and live, so a reviewer following the links sees the current description
and screenshots rather than the old ones.
